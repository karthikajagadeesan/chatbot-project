# Workflow: Add UI Component
Use this to create a reusable component in the `@/components` directory.

## Steps
1. Ask for the component name and whether it needs state (`'use client'`).
2. Generate the file using Tailwind CSS for styling.
3. If it requires data, suggest using **TanStack Query** hooks.
4. Ensure it follows the PascalCase naming convention.
